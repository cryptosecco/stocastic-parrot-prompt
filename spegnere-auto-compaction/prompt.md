# Spegnere l’auto-compaction in Claude Code

- URL: https://stocasticparrot.ai/tutorial/spegnere-auto-compaction/
- Aggiornato: 2026-11-03
- Provato con: Claude Code 2.1.311 (2026-10-27)

```text
Controlla con claude --version che Claude Code sia alla 2.1.311 o successiva; se è più vecchio, fermati e dimmelo. Poi, nel file ~/.claude/settings.json, imposta "autoCompactEnabled": false e "idleCompaction": false. Se il file non esiste, crealo. Non toccare le altre chiavi. Prima di salvare mostrami il file com’è ora e come diventa, e aspetta il mio sì.
```
