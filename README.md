## Italiano

I prompt degli articoli di [Stocastic Parrot](https://stocasticparrot.ai), uno per cartella, in italiano e in inglese. Il testo è quello che si copia dall’articolo, alla lettera.

### I prompt

- [Usi agenti AI? Sei a rischio: il prompt per metterti al sicuro](https://stocasticparrot.ai/sicurezza/brotli-rce/): [in italiano](brotli-rce/prompt.md), [in inglese](brotli-rce/prompt.en.md)
- [L’igiene di Claude Code](https://stocasticparrot.ai/spiegoni/igiene-claude-code/): [in italiano](igiene-claude-code/prompt.md), [in inglese](igiene-claude-code/prompt.en.md)
- [Spegnere l’auto-compaction in Claude Code](https://stocasticparrot.ai/tutorial/spegnere-auto-compaction/): [in italiano](spegnere-auto-compaction/prompt.md), [in inglese](spegnere-auto-compaction/prompt.en.md)

### Le versioni

Ogni cambio a un prompt è un commit: la storia di un file si legge con `git log -- <cartella>/prompt.md`, o dal pulsante «History» di GitHub. L’intestazione di ogni file dice a quale articolo appartiene, quando l’articolo è stato aggiornato l’ultima volta e, se c’è, con che cosa è stato provato. Dall’articolo si arriva qui con il link «Versioni e storia su GitHub», accanto al pulsante «Copia».

## English

The prompts from the articles on [Stocastic Parrot](https://stocasticparrot.ai), one per folder, in Italian and in English. The text is exactly what you copy from the article.

### The prompts

- [Using AI agents? You’re at risk: the prompt that keeps you safe](https://stocasticparrot.ai/en/security/brotli-rce/): [in English](brotli-rce/prompt.en.md), [in Italian](brotli-rce/prompt.md)
- [Claude Code hygiene](https://stocasticparrot.ai/en/explainers/claude-code-hygiene/): [in English](igiene-claude-code/prompt.en.md), [in Italian](igiene-claude-code/prompt.md)

### Versions

Every change to a prompt is a commit: you can read a file’s history with `git log -- <folder>/prompt.en.md`, or from the “History” button on GitHub. The header of each file says which article it belongs to, when the article was last updated and, if there is one, what it was tested with. From the article you get here with the “Versions and history on GitHub” link, next to the “Copy” button.
